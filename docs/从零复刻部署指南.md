# 交互式多媒体终端 · 从零复刻部署指南

适用版本：构建号 **1120q**，系统名「交互式多媒体终端」。
目标：零基础照着做，用交付包在自己的电脑或 GEC6818 开发板上跑出同样的系统。全部命令都可以直接复制粘贴。

---

| 你有什么 | 想做什么 | 看哪一节 |

| 有 GEC6818 开发板 + 800×480 触摸屏 | 在板子上真正跑起来 | 第 3 节，这是主流程 |
| 还想自己改代码、重新编译 | 从源码重新构建 | 第 4 节，进阶 |

不需要从头写代码。交付包里已经把编译好的程序、字体、图片和文档都装好了。

## 1. 拿到包先确认三件事

1. 解压交付包，能看到四个文件夹：`1.开发板运行包`、`2.Windows预览包`、`3.项目源码`、`4.项目文档`，以及这份指南。
2. 打开 `校验清单_SHA256.txt`，里面有每个文件的校验值。想核对的话，在电脑上装好 Python 后执行：

```powershell
python -c "import hashlib,pathlib,sys; p=pathlib.Path(sys.argv[1]); print(hashlib.sha256(p.read_bytes()).hexdigest(), p.name)" "1.开发板运行包/terminal-arm-1120q"
```

   打印出来的一串字符应和清单里对应行一致。小白可以跳过这步，不影响运行。

3. 记住两个数字：**屏幕 800×480**，**演示账号 678678 / 678678**。后面会用到。

## 2. 玩法一：Windows 电脑上看效果

不用开发板，不用装任何软件。

1. 进入 `2.Windows预览包`，把整个文件夹解压到一个**不含中文和空格的路径**，比如 `D:\terminal-demo`。（若所在电脑路径含中文导致启动失败，改到纯英文路径再试。）
2. 双击里面的 `run-preview.cmd`。
3. 出现一个 800×480 的窗口就是成功了。窗口标题写着 desktop simulation，表示这是电脑模拟，不是开发板实机。
4. 操作方式：鼠标**按下 → 拖动 → 松开**对应触摸屏的按下、滑动、抬起。登录时按屏幕上的九宫格输入 `678678`，再输一遍密码，点右下角「确认」。
5. 想退出直接关窗口。画的作品存在 `data/drawings`，重进相册就能看到。

## 3. 玩法二：GEC6818 开发板上跑（主流程）

### 3.1 需要准备

- GEC6818 开发板一台，配 800×480 触摸屏；
- 供电、串口线（用来在电脑上敲命令看屏幕输出）；
- 二选一：一个 U 盘 / SD 卡（方式 A），或者一根网线让板子和电脑连在同一个局域网（方式 B）；
- 电脑上装一个串口终端，比如 SecureCRT、PuTTY 或 MobaXterm。

程序不烧录系统、不改内核，只用到板子自带的 framebuffer 显示和触摸屏，所以不用重装板子系统。

### 3.2 方式 A：U 盘 / SD 卡整包拷贝（新手推荐）

1. 把 `1.开发板运行包/GEC6818-board-1120q.tar.gz` 拷到 U 盘或 SD 卡，插到开发板上。
2. 在串口终端里确认 U 盘挂载点。常见的是 `/mnt/udisk`、`/media/sda1` 或 `/mnt/usb`，用下面的命令看：

```sh
mount | grep -Ei 'sd|usb|udisk'
```

   假设挂在了 `/mnt/udisk`（不是的话换成你看到的实际路径）。

3. 在开发板上建立目录并解压：

```sh
mkdir -p /mnt/terminal
tar -xzf /mnt/udisk/GEC6818-board-1120q.tar.gz -C /mnt/terminal --strip-components=1
cd /mnt/terminal
chmod +x bin/terminal run.sh
```

4. 跳到 3.4 继续。

### 3.3 方式 B：网线 + 电脑 HTTP 服务（只换程序最快）

适合已经装过旧版本、只想换新程序的情况：只传 1.5MB 的单个文件，不用解压整包，账号和作品都保留。

**第一步：在电脑上起一个临时文件服务。**

1. 把 `1.开发板运行包/terminal-arm-1120q` 复制到一个单独的文件夹，比如 `D:\board_share`。
2. 在这个文件夹里打开命令行（在文件夹地址栏输入 `cmd` 回车），执行：

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

3. 看到 `Serving HTTP on 0.0.0.0 port 8000` 就说明服务起来了。**这个窗口不能关**，关了板子就下载不到文件。
4. 查电脑的 IP 地址。另开一个命令行窗口，执行 `ipconfig`，找到类似 `192.168.1.x` 或 `192.168.137.x` 的地址，记下来。下面假设是 `192.168.1.3`，实际请换成你查到的。

> 常见故障：板子上 `wget` 报 `Connection refused`，十有八九是这个 HTTP 服务窗口被关了，或者电脑 IP 变了。回到第 2 步重起服务、重新查 IP。

**第二步：在板子上下载并替换程序。**

在串口终端里执行（把 IP 换成你自己的）：

```sh
cd /mnt/terminal
wget -O bin/terminal http://192.168.1.3:8000/terminal-arm-1120q
chmod +x bin/terminal
```

如果板子上原来还没有整个目录，就先用方式 A 把整包放上去，以后再用方式 B 更新单个程序。

### 3.4 找到触摸屏的 event 节点

不同板子的触摸节点编号可能不一样，先查出来：

```sh
cat /proc/bus/input/devices
```

在输出里找带 `touchscreen`、`Touch`、`gslx680` 之类字样的那一段，看它下面 `Handlers=` 一行里的 `eventN`，比如 `event0`。下面命令里的 `/dev/input/event0` 都要换成你查到的实际节点。

### 3.5 第一次启动与验证

```sh
cd /mnt/terminal
./run.sh --fb /dev/fb0 --touch /dev/input/event0
```

屏幕出现登录页就成功了。串口会打印启动信息，包括屏幕尺寸、位深和触摸量程，类似：

```
LCD 800x480/32, stride=3200; touch X=0..1024 Y=0..600 via ABS_X/ABS_Y
```

想跳过登录直接进主页，可以加参数：

```sh
./run.sh --fb /dev/fb0 --touch /dev/input/event0 --skip-login
```

**第一次启动的四个检查点：**

1. 屏幕正常显示，中文不乱码（字体在 `res/simfang.ttf`）。
2. 输入账号 `678678`、密码 `678678`，点右下角「确认」能进主页。
3. 主页三张卡片（电子相册 / 小游戏 / 创意画板）能点进去，每页都能返回。
4. 画板画几笔、点保存，返回主页再进相册能看到刚保存的作品。

程序一启动就会自动创建 `data/app.log`，这是运行日志，排查问题时很有用，用法见第 6 节。

## 4. 玩法三：从源码重新编译（进阶）

交付包的 `3.项目源码` 里有完整工程。用 Git 的话也可以直接从 GitHub 拉：

```sh
git clone https://github.com/WWWW11223344/interactive-multimedia-terminal.git
```

### 4.1 Windows 桌面版

需要：MinGW GCC 和 CMake（把它们的 `bin` 目录加进系统 PATH）。在工程根目录执行：

```powershell
cmake -S . -B build-host -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build-host -j 4
ctest --test-dir build-host --output-on-failure
.\build-host\terminal.exe --root .
```

5 项自动测试应全部通过。用板卡的 SDK 编译器也能构建 ARM 版：

```sh
make CROSS_COMPILE=arm-linux-
```

### 4.2 ARM 板端版（Windows 上用 Zig 交叉编译）

需要 Zig 0.13.0 的 Windows x86_64 版本。官方下载地址见 `https://ziglang.org/download/index.json`，官方 ZIP 的 SHA256 是
`d859994725ef9402381e557c60bb57497215682e355204d754ee3df75ee3c158`，下载后务必核对一致。工具链体积大，不包含在交付包里。

把 `zig.exe` 放到 `G:/io/outputs/toolchains/zig-windows-x86_64-0.13.0/`（和本工程同级），然后在工程根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_arm.ps1
```

成功会打印 `Built build-arm/terminal`。产物是 ARMv7-A、EABI 软浮点、静态链接 musl 的 ELF 程序，可以直接放进板端运行包的 `bin/terminal`。构建脚本会检查退出码和文件时间戳，不会「假成功」。

> 不要改动 `inc/terminal.h` 里的 `APP_BUILD` 之外的东西，改版本号只需改这个宏，重新编译后界面右下角和串口首行会同步显示新构建号。

## 5. 演示操作速查

样机触摸屏有一条**中段横向失效带**：下边界约在 y=257，键盘最上面一行 `1 2 3` 按不了，其余 `4 5 6`、`7 8 9`、`删除 0 确认` 都正常。这是**屏体硬件故障**，换一块正常的屏即可恢复，不是程序问题。程序已经把可点控件都排到了可操作区域。

| 页面 | 怎么操作 |
| --- | --- |
| 登录 | 输 `678678` 两次，点右下角「确认」。不要点左边那个大的「登录」按钮，它在失效带里 |
| 小游戏 | 竖排四个入口全在可点区域：2048 / 五子棋 / 井字棋 / 中国象棋 |
| 2048 | 滑动操作，没有方向键；从棋盘下半部往上/下/左/右滑 |
| 井字棋 | 电脑的圆已修复能正常显示；棋盘下半部分的格子能落子 |
| 画板 | 工具栏、色板、粗细都在上方可点区；画布中段一条画不出来，上段和下段正常 |
| 相册 | 只支持未压缩的 24/32 位 BMP，最多 128 张，损坏的文件会提示但不中断 |

想验证失效带是不是硬件问题，在板子上跑 `./run.sh --sweep`：屏幕被切成 24 条横带逐条计数，失效的那几条是红柱或空柱。用第三方原版程序在同一块屏上跑，症状一样，可以作为佐证。

## 6. 运行日志怎么用

程序一启动就自动创建 `data/app.log`，同时每条日志也会打到串口，格式是「月-日 时:分:秒 [级别] 内容」。四个级别：ERROR 错误、WARN 警告、INFO 信息、DEBUG 调试。

已经埋点的事件：程序启动与退出、触摸设备断开、页面切换（如 主页 -> 相册）、登录成功与失败、注册成功与失败、画板作品保存成功与失败。日志只记账号，不记密码明文。

在串口终端里回看：

```sh
cat data/app.log
tail -20 data/app.log
```

日志最大 64KB，写满自动截断重写并留一条 `log rotated`，不会把板子的分区撑满。

> 如果日志时间显示成 `01-01 00:xx`，是因为板子没有 RTC、没同步系统时间，不影响功能。要正确时间可在板上执行 `date -s "2026-11-24 09:51:00"`，但每次重启会丢。

## 7. 常见问题照着排

| 现象 | 原因与处理 |
| --- | --- |
| 双击预览没反应 / 闪退 | 路径含中文或空格，把整个文件夹移到 `D:\terminal-demo` 这样的纯英文路径 |
| `wget` 报 Connection refused | 电脑上的 HTTP 服务没起，或电脑 IP 变了。回 3.3 重起服务、重新查 IP |
| `Permission denied` | 权限没加上，执行 `chmod +x bin/terminal run.sh` |
| `Exec format error` | 把 Windows 的 `terminal.exe` 拷到板子上跑了。板子要用 `bin/terminal` |
| `Resource initialization failed` | 没在包根目录启动，或字体/图片缺失。先 `cd` 到包根目录，确认 `res/simfang.ttf` 和 `res/game/0..11.bmp` 在 |
| `Unsupported framebuffer` | 屏幕不是 800×480 或位深不对。保存启动日志，核对 `/dev/fb0` 参数 |
| 触摸完全没反应 | event 节点选错了。回 3.4 重新查 `/proc/bus/input/devices` |
| 部分区域点不动 | 大概率是那块屏的失效带，见第 5 节；换屏后可用 `--sweep` 复验 |
| 保存作品失败 | `data/drawings` 不可写或板子空间满。执行 `df -h` 看剩余空间，清理无用文件 |
| 账号密码对却登不进去 | 旧包在 `data/accounts.txt` 留下了旧账号。本版已改为按账号名追加，若仍异常可删除该文件中的旧行后重启 |
| 日志时间是 01-01 | 板子没同步系统时间，见第 6 节说明 |
